# Boiler Safety Monitor — Веб-демо

Интерактивная демонстрация системы видеомониторинга с сценарной симуляцией событий.

## Запуск

```bash
python server.py
```

Откройте http://localhost:8080 в браузере.

## Сценарии

Каждый сценарий относится к категории инструментов Hikrobot SC3000 (источник —
`Tools table v4.xlsx`, лист `Hikrobot SC3000 Tools`).

| Сценарий | Категория | Задача |
|----------|-----------|--------|
| **OCR** | 3 — Распознавание | Оптическое распознавание символов (дата, серийные номера) |
| **Diameter** | 1 — Измерение | Измерение диаметра окружности на ленте конвейера |
| **Registered** | 2 — Подсчёт | Интеллектуальный подсчёт объектов по типам |

## Возможности

- Автозапуск демо-ролиха при выборе сценария (без кнопок управления, `muted` — под autoplay-политику браузера)
- Воспроизведение видео с поддержкой перемотки (Range-запросы)
- Автоматическая генерация событий по расписанию сценария
- Таблицы событий и уведомлений в реальном времени
- Блок «Возможности категории» — остальные инструменты категории выбранного сценария,
  с всплывающими подсказками-описаниями (берутся из `TOOL_DESCRIPTIONS` / `CATEGORY_DESCRIPTIONS` в `js/scenarios.js`)
- Выбор сценария через модальное окно (клик по бейджу в навбаре)

## Структура проекта

```
├── index.html          — интерфейс (Bootstrap 5)
├── reports.html        — страница отчётов
├── js/
│   ├── scenarios.js    — сценарии, категории и справочник инструментов
│   ├── app.js          — логика приложения
│   └── reports.js      — мок-данные и рендеринг отчётов
├── css/style.css       — пользовательские стили
├── lib/                — Bootstrap 5 + Bootstrap Icons (vendored)
├── video/              — видеофайлы (.webm, .mp4)
└── server.py           — HTTP-сервер (Python stdlib)
```

## Добавление нового сценария

1. Положите видео в папку `video/`
2. Добавьте объект в `SCENARIOS` в файле `js/scenarios.js`, указав `category`,
   `categoryName`, `currentTool` и `categoryTools`
3. Добавьте `<option>` в `<select>` в `index.html`
